# Bài tập 1 - ReactJS (Vite) + HTML/CSS + React Router

Website chủ đề **SmartStay — Cho thuê & Quản lý phòng trọ** được xây dựng bằng ReactJS (Vite), CSS tùy chỉnh và tích hợp `react-router-dom` để điều hướng đa trang.

## Tính năng chính
- Trang chủ (`/`) với giao diện HTML/CSS tùy chỉnh (`src/styles/main.css`).
- Các trang con: Danh sách phòng (`/rooms`), Giới thiệu (`/about-us`), Liên hệ (`/contact`).
- Hỗ trợ chuyển trang khi click menu hoặc truy cập trực tiếp qua URL (ví dụ `http://localhost:3000/about-us`).

## Hướng dẫn chạy
```bash
npm install
npm run dev
```
Truy cập `http://localhost:3000` (hoặc `http://localhost:3000/about-us`).
